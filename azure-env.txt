# Proxena Backend — Azure App Service Environment Variables
#
# HOW TO USE
# ──────────────────────────────────────────────────────────────────────────────
# Option A  Azure Portal
#   App Service → Settings → Environment variables → "+ Add"
#   Paste each NAME and VALUE individually. Click Save → Confirm.
#
# Option B  Azure CLI (bulk import from this file)
#   1. Fill in every <REPLACE_...> placeholder below.
#   2. Run:
#        az webapp config appsettings set \
#          --resource-group <your-resource-group> \
#          --name <your-app-service-name> \
#          --settings \
#            NODE_ENV="production" \
#            PORT="8080" \
#            ... (one --settings flag or list them all)
#
#   Or use the JSON format accepted by:
#        az webapp config appsettings set --settings @azure-env.json
#   (convert this file to JSON if using that approach)
#
# IMPORTANT NOTES
# ──────────────────────────────────────────────────────────────────────────────
# • Do NOT commit this file to Git once you have filled in real secrets.
# • Azure sets PORT automatically — the value below (8080) matches Azure's
#   default for Linux Node apps. Do not set PORT to 3000 in production.
# • FIREBASE_PRIVATE_KEY must keep its literal \n characters — do NOT expand
#   them to real newlines when pasting into the Azure Portal text field.
